## ☕ Starbucks Landing Page

Este projeto é uma landing page inspirada no site da Starbucks, desenvolvida com foco em design moderno, responsividade e experiência do usuário. A aplicação simula a identidade visual da marca, destacando produtos, estilo e interatividade.

## 🚀 Sobre o Projeto

A proposta do projeto é recriar uma interface semelhante à da Starbucks, aplicando conceitos de front-end moderno e boas práticas de desenvolvimento web.

O site apresenta uma estrutura organizada e visualmente atrativa, com elementos que reforçam a identidade da marca, como cores, tipografia e imagens relacionadas ao universo do café.

## 🧩 Funcionalidades

- Layout moderno e responsivo 📱💻
- Seções organizadas (ex: destaque, produtos, informações)
- Navegação simples e intuitiva
- Elementos interativos com efeitos visuais
- Destaque para produtos e bebidas
- Design inspirado na experiência real da Starbucks

## 🛠️ Tecnologias Utilizadas

- HTML5 🟧
- CSS3 🟦
- JavaScript 🟨 


## 🎯 Objetivo

O principal objetivo deste projeto é:

- Praticar desenvolvimento front-end
- Melhorar habilidades em layout e responsividade
- Trabalhar com design inspirado em marcas reais
- Criar uma experiência visual agradável para o usuário

## 📱 Responsividade

O site foi desenvolvido para funcionar bem em diferentes dispositivos, garantindo uma boa experiência tanto em:

- Desktop 🖥️
- Tablet 📲
- Smartphone 📱
